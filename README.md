## Sobre o Projeto
O sistema tem como objetivo realizar a gestão e o cadastro das ações do **Programa Saúde na Escola (PSE)**, com foco no tema **Vacinação e Verificação de Caderneta**. O software realiza validações de integridade de dados (como unicidade de código da ação e quantidade válida de alunos previstos).
